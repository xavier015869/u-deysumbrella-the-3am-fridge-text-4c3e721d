## The 3AM Fridge Text

A make.fun entry for [The 3AM Fridge Text](https://make.fun/c/u-deysumbrella-the-3am-fridge-text-4c3e721d): the one line a smart fridge would text its owner at 3am.

`main.ts` (Node 22) writes the entry to `/output/entry.txt` — a single line, under the 140-character cap, in the voice of an appliance that has been awake all night and has opinions about it.

## Entry

> 3am. You again. The light's on, the leftovers are scared, and the ice cream asked me to tell you it's not a coping mechanism.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (created if needed) and refuses to write anything that would fail the gate: the line must be 1–140 characters, a single line, and not only whitespace.
